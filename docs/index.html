DataScraper

Extract structured data from any website. CSS selectors, scheduling, concurrency, and CSV/JSON export — in a free, native Windows app.

CSS Selector Extraction

Pull text, HTML, attributes, links, and images from any page using standard CSS selectors you already know.

Recurring Schedules

Set interval-based jobs to keep your data fresh automatically. Perfect for price tracking and monitoring.

CSV & JSON Export

Auto-export results in industry-standard formats. Everything stores locally in SQLite — zero cloud lock-in.

Concurrent & Fast

Rust-powered parallelism with throttle controls. Built-in retry, pagination following, and proxy support.

No Setup, No Cloud

Single 17 MB executable. No installation, no account, no subscriptions. Your data stays on your machine.

Dark / Light / System

A native, responsive interface that matches your Windows theme. Import/export job configs as YAML.

Quick Start

  1. Download the latest data-scraper.exe from Releases.
  2. Open the Scraper tab and click + New Job.
  3. Enter a URL and add CSS selectors for the data fields you need.
  4. Hit Test to preview, then Run to scrape.
  5. Results land in the Results tab — export to CSV or JSON anytime.
DataScraper is free and open source (MIT). Built with Rust, eframe, and Tokio.
